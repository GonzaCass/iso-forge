# Catalogo y flujo de descarga

Referencia: UI/UX Pro Max, commit 477bcb28c9812b385cb51a4605ddf30d7b2266e2.
Estilo verificado: Dark Mode (OLED) para herramientas de desarrollo.
Referencia complementaria: Data-Dense Dashboard y Bento Box Grid (busqueda "dashboard sidebar table").
Paleta aplicada: fondo #0F172A, tarjetas #1B2336, accion #22C55E con texto #0F172A.
Tipografias: IBM Plex Sans para interfaz, JetBrains Mono para metadatos. Fuentes empaquetadas localmente.

La recomendacion automatica de una landing FAQ no corresponde a una app de escritorio.
Se reemplaza ese patron por navegacion lateral, tarjetas de producto, formulario y resumen.
La recomendacion de scroll reveal tampoco se aplica: solo transiciones de estado de 160ms.

Requisitos: formularios etiquetados; foco visible; errores concretos; progreso real; historial real;
sin cifras ficticias; sin iconos emoji; sin recursos externos cargados en el renderer;
disponibilidad y version real de imagen explicadas; movimiento reducido; columnas adaptables.
